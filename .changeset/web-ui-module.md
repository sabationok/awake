Web UI тепер окремий модуль у боковому меню: адреси і збірка, «Вхід» (пароль і активні вебсесії), «Мережі» (довірені Wi-Fi та Upstash), «Пристрої». Ці рядки переїхали зі сторінок «Сервер», «Підключення» і «Пристрої»; у вебі видно стан, а змінювати можна лише в аппці на Mac.
