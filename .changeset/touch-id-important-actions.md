Важливі дії тепер підтверджуються Touch ID (або паролем Mac): зміна пароля Web UI, ключі Remote KV Store, дозвіл на приєднання нового пристрою і відкликання пристрою. Пароль Web UI задається в модалці з полем «Повторіть пароль». Однопольові форми в рядку мають підпис, поле в рамці і кнопки окремим рядком. Меню у вузькому вікні має іконки і плавно ховається вбік.
