# Awake (mac-manager): специфікація

Робоча назва апки — Awake. Суть змінилась: це менеджер Mac, де керування сном є одним із розділів.

## Мета

Одна апка в меню-барі й у вікні для керування живленням і сном Mac, а також для сповіщень і віддалених команд через Telegram.

## Розділи

| Розділ | Що робить | Статус |
|---|---|---|
| Сесія | Блокує сон на час, повертає його по таймеру, при низькому заряді або перегріві | є |
| Стан | Сон, батарея, температура (тиск системи) | є |
| Трекінг | Історія сесій з журналу: час, батарея на початку й наприкінці, причина завершення | є |
| Дисплей | Гасіння екрана | є |
| Безпека | Пороги батареї і температури | є |
| Telegram | Токен і чат, перемикачі подій, команди боту | є |
| Дозвіл | Права на керування сном | є |
| Журнал | Події за 30 днів | є |

## Принципи

- Усе, що потрібно root, іде через sudoers з точними аргументами, не через пароль у коді.
- Дозволи на двох рівнях: Mac-аппка просить у системи (правила sudoers `/etc/sudoers.d/mc-<дозвіл>`, геолокація, Bluetooth) через системний діалог адміністратора, модулі агента — в аппки і не отримують більше, ніж видала система. Інсталяція пароля не просить; старі правила `awake*` аппка один раз переносить на `mc-*`.
- Закриття апки повертає сон, якщо сесія активна. Після збою сон повертається при старті за файлом PID.
- Журнал — єдине джерело історії. Трекінг нічого окремо не зберігає.
- Сповіщення Telegram фільтруються за `TG_EVENTS`. Відповіді на команди завжди надсилаються.

## Поза межами поточної версії

- Збереження температури кристала: лише тиск системи з офіційного API.
- Оновлення через Sparkle: апдейтер поки не підключений.
- App Store: прямий вихід не сумісний із sudoers і приватними API.

## Джерела

- Журнал: `~/.config/awake/awake.log`
- Налаштування Telegram: `~/.config/awake/telegram.env`
- PID активної сесії: `~/.config/awake/session.pid`
